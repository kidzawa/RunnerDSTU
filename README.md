#RunnerDSTU 

Учебный проект в жанре раннера с элементами шутера, разработанный на движке Unity.

​Об игре

​RunnerDSTU — это динамичный раннер (в стиле Subway Surfers) с видом от третьего лица, где игроку нужно продвигаться вперед по коридорам, отстреливаться от врагов и следить за боезапасом. Управление завязано на классическую клавиатурную раскладку WASD.

​Ключевые особенности и механики

​Система стрельбы: Оружие с ограничением патронов, перезарядкой и визуальными эффектами. 

​Аудиосопровождение: Динамические звуковые эффекты для стрельбы, прыжков и шагов.

​Классическое управление: Удобное передвижение на клавиатуре (WASD) и стрельба с помощью мыши. 

​Технологии

​Движок: Unity (6000.5.2f1) 

​Язык программирования: C#

​Платформа: ПК (Windows)
